# ⛏️ Garimpo

Encontre empresas da sua cidade sem site e ofereça seus serviços pelo WhatsApp.

Veja a arquitetura completa em [ARCHITECTURE.md](ARCHITECTURE.md).

## Requisitos

- Node 24 (`nvm use`)
- npm (este projeto usa **apenas npm**)

## Comandos

```bash
npm install          # instala todos os pacotes do monorepo
npm run dev          # sobe o app web (http://localhost:3000)
npm run build        # build de tudo
npm run test         # testes (Vitest)
npm run lint         # lint + verificação das fronteiras entre camadas
npm run typecheck    # checagem de tipos
```
